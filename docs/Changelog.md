# Changelog

按日期分段记录（`## YYYY-MM-DD`，新 → 旧）。每条只写「做了什么 / 改了什么 / 修了什么」，原因与排查过程见 `docs/Development.md` 与 `DADA/MEMORY.md`。

## 2026-10-23

### 新增 / 改变

- 高级功能新增「任务模式」：两枚互斥选项「存储在本地」（默认，整理模式不设置时间间隔整理文件）/「存储在网盘」（整理模式按「自动休息」间隔整理文件，上一次整理完成到下一次整理开始之间至少间隔自动休息设定时间，防止网盘目录缓存未刷新导致整理失败）；配置保存在 `switch_on` 开关组（`task_store_local` / `task_store_netdisk`），旧整理模式的独立 bool 键（`organize_local_no_interval` / `organize_netdisk_rest_interval`）已废弃并自动升级迁移。
- 刮削模式整理模式：删除下方两枚互斥的间隔复选框（功能已迁移到高级功能任务模式），运行时整理间隔逻辑由任务模式决定（本地不限制 / 网盘按自动休息间隔）。

### 修复

- 配置升级：旧配置两开 / 全关时归一到默认「存储在本地」或更安全的「存储在网盘」；保存时校验互斥并写入 `switch_on`。
- 运行时整理间隔等待：`organize_netdisk_rest_enabled()` 改为读取 `Switch.TASK_STORE_NETDISK` 开关状态，与整理模式运行时判断保持一致。
- 高级页「任务模式」行对齐：「存储在本地」「存储在网盘」两枚复选框上移，与「任务模式：」标签严格水平居中（标签行高补到 30，行内 spacer 全部去掉，改由两枚复选框均分整行）；「存储在网盘」左移，与下一行「暗黑模式」严格上下对齐（任务模式行改成与「隐藏图标」行同构的 `y=-10`、`550×51` 内嵌 widget，第 2 枚复选框恒落在行中点，窗口宽度变化也不会错位）。
