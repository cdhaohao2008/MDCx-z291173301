                    其下按分组顺序铺全部站点、每个站只出现一次（就是上面六组默认名单
                    同一个常量 TYPE_DEFAULT_SITES，界面与默认行为不会各走一套）：
                        有码｜无码｜素人｜FC2｜欧美｜国产      ← 最上面一行，标题 chip
                        DMM  DMM_API  LibreDMM  AVEntertainments  …  ← 铺放次序 = 各组首次

                    被当成站点混进「启用网站」或复制结果。单击某个标题 chip = 把该组全部网站
                    加入「启用网站」（联动组自动补齐）；名单挂在 chip 自己身上
                    （SITE_GROUP_ROLE 记标题序、SITE_GROUPS_ROLE 记各组成员），
                    所以点哪个标题就是哪一份名单，不会把末尾零散站点算进上一组。

                    + accent 边框区分，悬停时高亮示意可点；chip 矩形由绘制时算出并缓存回
                    控件，点击命中判定复用同一份矩形（样式表会改 item 字体，按 self.font()
                    重算会与实际绘制错开几像素）。
    右键            点站点 → 复制该站名；点标题 chip → 复制该组名单（如「有码」30 站、
                    「FC2」15 站，互不相等）；点空白处（含标题 chip 之间的空隙）→ 复制整张
                    列表（逗号分隔，与对话框上方输入框同格式，可直接粘回）。
    启用网站列表    顺序完全由用户拖拽决定，与候选区分组无关；「全部添加」写入的仍是
                    爬虫注册序，不受分组影响。
